Fredoka-SemiBold.ttf is the SemiBold (wght=600, wdth=100) instance of the variable
font Fredoka by The Fredoka Project Authors (https://github.com/hafontia/Fredoka-One),
taken from https://github.com/google/fonts/tree/main/ofl/fredoka and instanced with
`fonttools varLib.instancer`. It is licensed under the SIL Open Font License 1.1, see OFL.txt.
